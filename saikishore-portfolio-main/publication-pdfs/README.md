# Publication PDFs

Place publication PDF files in this folder before enabling their download button on `publications.html`.

Suggested names:

- `hexagonal-microcantilever-beams.pdf`
- `leaf-based-microcantilever-beams.pdf`
- `closed-loop-mems-accelerometer.pdf`

Use the matching file path in the publication entry, for example:

```html
<a href="publication-pdfs/hexagonal-microcantilever-beams.pdf" download>Download PDF</a>
```
