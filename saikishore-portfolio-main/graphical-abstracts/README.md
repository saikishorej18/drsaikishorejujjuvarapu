# Graphical abstracts

Add one image per publication to this folder, then replace the matching `span` with a link in `publications.html`.

Suggested filenames:

- `hexagonal-microcantilever-beams.png`
- `leaf-based-microcantilever-beams.png`
- `closed-loop-mems-accelerometer.png`

Use a link such as:

```html
<a href="graphical-abstracts/hexagonal-microcantilever-beams.png" target="_blank">
  <i class="fas fa-image"></i> Graphical Abstract
</a>
```
